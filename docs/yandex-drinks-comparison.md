- Бутылочные Coca-Cola250мл950₸, Вода Asu250мл950₸, Gracio250мл950₸ и Salam Cola250мл750₸ присутствуют только в полученном тексте доставки. Они не добавлены в зальное меню. Salam Cola помечена «Будет позже».
- В доставке не найдены раздел милкшейков, какао, ряд авторских напитков, имбирный чай, Мохито и Манго-маракуйя как отдельные строки из фото. Это не доказательство отсутствия в заведении.

## Решение для импорта

Цены и объёмы из фото сохранены как самостоятельный источник. Доставка используется только для сравнения; данные Django не перезаписаны значениями Яндекс Еды. Delivery-only позиции не созданы. Для единого каталога нужно отдельное подтверждение владельцем канала продаж, точных объёмов и актуальности цен.
